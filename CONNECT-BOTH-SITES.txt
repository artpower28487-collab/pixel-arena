The two site folders now contain Supabase integration code and the same project URL/publishable key. Finish setup in Supabase
1. Open the Supabase project whose URL is in supabase-config.js.
2. Open SQL Editor, paste the full contents of supabase-setup.sql, and run it. This creates the bookings/offers tables, access policies, and live booking updates.
3. In Authentication settings, disable public sign-ups.
4. In Authentication > Users, create/confirm the owner account artpower28487@gmail.com. Set its password to PixelArena-<PIN>-Portal! using a private 8–12 digit PIN. Example: PIN 12345678 means account password PixelArena-12345678-Portal!
5. The owner portal asks only for that PIN; it uses the owner email internally for Supabase sign-in. Do not use the old demo PIN 6527. Keep the chosen PIN private.
6. Deploy each complete site folder over HTTPS. Keep supabase-config.js beside its index.html. Do not deploy only the standalone HTML file: browser-to-Supabase requests need an HTTPS website origin.


Current limits

For recovery links, configure the deployed HTTPS portal URL in Supabase Auth URL settings. The booking request starts as pending; the venue still confirms it.
